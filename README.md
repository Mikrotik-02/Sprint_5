# Тесты для Stellar Burgers

В проекте реализованы UI-автотесты для сервиса Stellar Burgers:
`https://stellarburgers.education-services.ru/`.

Тесты написаны на `pytest` и `Selenium WebDriver`.

## Покрытая функциональность

### Регистрация
- успешная регистрация пользователя
- проверка ошибки при вводе некорректного пароля

### Вход
- вход по кнопке «Войти в аккаунт» на главной странице
- вход через кнопку «Личный Кабинет»
- вход через кнопку «Войти» на странице регистрации
- вход через кнопку «Войти» на странице восстановления пароля

### Переходы
- переход в личный кабинет по кнопке «Личный Кабинет»
- переход из личного кабинета в конструктор по кнопке «Конструктор»
- переход из личного кабинета в конструктор по логотипу Stellar Burgers

### Выход из аккаунта
- выход из аккаунта по кнопке «Выход» в личном кабинете

### Раздел «Конструктор»
- переход к разделу «Булки»
- переход к разделу «Соусы»
- переход к разделу «Начинки»

## Структура проекта

- `tests/` — тесты по функциональным разделам
- `locators.py` — локаторы элементов
- `data.py` — URL страниц
- `helpers.py` — вспомогательные функции для регистрации и входа
- `conftest.py` — фикстуры `driver` и `user_data`

## Запуск тестов

Установить зависимости:

```bash
pip install pytest selenium
```

Запустить все тесты:

```bash
pytest tests -v
```

Запустить отдельный файл:

```bash
pytest tests/test_registration.py -v
```

Запустить отдельный тест:

```bash
pytest tests/test_registration.py::test_registration_with_valid_data_redirects_to_login_page -v
```
